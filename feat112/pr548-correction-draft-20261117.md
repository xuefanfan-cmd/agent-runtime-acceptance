对上一条评论（201285073）第五节的两处更正：

1. **第 7 条的格式正则写反了。** 应为 `^FEAT-\d{3}-[A-Z]\d+(-[a-z][a-z0-9]*)?(\.\d+)?$`，即变体在前、测试点在后，与 D1 §6c 的 `FEAT-NNN-{domain}{seq}[-{variant}][.{point}]` 一致。上一条写成了测试点在前，按那个正则，同时带变体和测试点的 ID（如 `D1-run.1`）会被判为格式错误。

2. **第 8 条“存量 ID 不改名”建议改为：编号错误时允许修改。** 已有 ID 原则上不改；编号错误时（如不符合本规则的分级或格式）允许修改，原 ID 登记在 §5 末尾“已撤销 ID 与历史写法”且不再使用，测试代码与文档引用在同一次变更中更新。FEAT-112 testplan 在 PR 549 中即按此修正了不符合规则的编号（如 `D1a` → `D1-run`、`E5.1`–`E5.6` → `E13`–`E18`、`K-rep1`–`K-rep3` → `K18`–`K20`）。
